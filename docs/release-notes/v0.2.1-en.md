# Renewo v0.2.1

Renewo v0.2.1 adds a subscription group view to the public status page, so larger subscription lists can be browsed by collapsible groups. The default cloud backup remote path is updated to the brand name Renewo, and a mobile credential card overflow issue is fixed.

[中文 ->](./v0.2.1-zh.md)

---

## New Features

- Public status page group view: subscriptions can be displayed in groups, each with a name and logo. Groups are collapsible/expandable, and a toggle in the header switches between grouped and flat layouts.

---

## Improvements

- Cloud backup (WebDAV/S3) default remote path changed from renewlet to the brand name Renewo. Existing saved configurations are unaffected; only new setups or empty paths use the new default.

---

## Bug Fixes

- Fixed mobile credential card overflow where long URLs would stretch the card beyond the viewport, hiding content on the right side.
